# Eco Log – Sistema de Controle Operacional

Projeto acadêmico desenvolvido como parte do Projeto Integrado Multidisciplinar II (PIM II), do curso de Análise e Desenvolvimento de Sistemas da UNIP.

O sistema foi desenvolvido em linguagem C e tem como objetivo demonstrar uma solução para auxiliar no controle operacional da Eco Log, uma empresa fictícia de logística reversa de resíduos eletrônicos.

## Funcionalidades

- Cadastro e consulta de lotes;
- Triagem e registro de pesagem dos resíduos;
- Controle de envios às recicladoras parceiras;
- Confirmação de entrega dos materiais;
- Histórico de movimentações;
- Geração de certificados e relatórios.

## Tecnologias utilizadas

- Linguagem C;
- Dev-C++;
- Arquivos `.txt` para armazenamento dos registros.

## Execução

O código-fonte pode ser aberto e executado em um ambiente de desenvolvimento compatível com a linguagem C, como o Dev-C++.

**Observação:** Este sistema é um protótipo acadêmico desenvolvido para fins educacionais, utilizando dados simulados.
